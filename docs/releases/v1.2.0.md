# douyin-skills v1.2.0

`v1.2.0` extends the Douyin discovery workflow with bounded public trending-
topic lookup and hardens browser reuse, detail loading, and publish-page
diagnostics.

## What's included

- `python scripts/cli.py get-trending-topics` reads up to 20 public topics.
- Trending results distinguish `ready`, `risk`, `empty_or_blocked`, and
  `page_drift` instead of treating an empty extraction as a successful empty
  list.
- Existing loopback Chrome debugging sessions are reused by default, including
  sessions already running in headed mode; `--headed` remains an explicit mode
  switch when needed.
- Detail lookup waits through the adapter's transient loading marker and uses
  the public content description when the document title is not useful.
- Publish validation and music selection report `wrong_page` when invoked
  outside the Creator Center photo-upload route.
- Synthetic, privacy-safe trending fixtures cover ready, risk, and page-drift
  states.

## Install or upgrade

With OpenClaw:

```bash
openclaw skills install git:zJay26/douyin-skills@v1.2.0
```

For a manual checkout:

```bash
git fetch --tags
git checkout v1.2.0
npm ci
python scripts/cli.py doctor
```

If you use the GitHub Release, download `douyin-skills-v1.2.0.zip` and
`SHA256SUMS`, verify the checksum, and extract the package into a new
directory. Local account data remains outside the repository by default and
must not be copied into a release package.

## Validation scope

The release gate covers 70 Python unit tests, 16 privacy-safe synthetic
fixtures, repository integrity validation, the 960×540 privacy-safe Demo,
Node.js syntax and CDP tests, Ruff lint and format checks, and a reproducible
release build.

The dated live smoke run confirmed environment readiness, an existing logged-in
Chrome session, AI keyword search, video detail lookup, and a clear
`wrong_page` result when publish validation was run on a video page. The live
hot-topic route currently exposed only its navigation shell, so the command
returned `page_drift` rather than claiming that no topics exist.

These checks validate the result contract and the observed environment; they
do not guarantee current live-page compatibility for every account, selector
version, captcha, interaction, or publishing flow.

## Boundaries

- Only the Douyin adapter ships in this release.
- Fixtures are synthetic and privacy-safe; they are not captured HTML or live
  page evidence.
- Captcha, identity checks, and risk controls are surfaced for human handling
  and are never bypassed.
- Publishing still requires validation and a separate explicit confirmation.
- No account, session, profile, QR code, phone number, or private-content data
  is included in the release package.
