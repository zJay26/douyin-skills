# douyin-skills v1.1.1

`v1.1.1` adds a maintainer-facing guide for authoring platform adapters. It
turns the existing `PlatformAdapter` boundary into a concrete checklist for
URL parsing, selectors, risk markers, safety semantics, privacy-safe evidence,
and release validation.

This is a documentation and validation release. The runtime API, result
contract, browser lifecycle, safety policy, and shipped platform set are
unchanged: only the Douyin adapter is implemented and advertised.

## What's included

- `docs/ADAPTER_AUTHORING.md`, with the complete contract surface and a
  workflow for implementing and reviewing a future adapter.
- A Python documentation contract test that checks the guide's authoritative
  references and safety/validation terms.
- README, ecosystem, roadmap, changelog, and release metadata links for the
  guide.

## Install or upgrade

With OpenClaw:

```bash
openclaw skills install git:zJay26/douyin-skills@v1.1.1
```

For a manual checkout:

```bash
git fetch --tags
git checkout v1.1.1
npm ci
python scripts/cli.py doctor
```

If you use the GitHub Release, download `douyin-skills-v1.1.1.zip` and
`SHA256SUMS`, verify the checksum, and extract the package into a new
directory. Local account data remains outside the repository by default and
must not be copied into a release package.

## Validation scope

The final release commit is gated by the repository's Python, Node.js, fixture,
packaging, lint, formatting, and documentation-integrity checks. The feature
PR must pass the Windows (Python 3.13 / Node.js 24) and Ubuntu (Python 3.9 /
Node.js 18) CI matrix before merge.

The release evidence includes 57 Python unit tests, 11 privacy-safe synthetic
fixture validations, repository integrity validation with the 960×540
40-second Demo, one Node.js CDP bridge test, Ruff lint/format checks, two
reproducible release builds, and a fresh-extraction version smoke test.

These checks validate the repository's adapter contract, documentation links,
and result semantics. They do not prove current live-page compatibility for a
future platform, every account, selector version, captcha, interaction, or
publishing flow.

## Boundaries

- Only the Douyin adapter ships in this release; no second platform is
  implemented or advertised.
- The guide does not authorize CAPTCHA, identity-check, or platform-risk
  bypasses.
- Existing human review rules and confirmed/unconfirmed result semantics remain
  in force.
- The release package contains repository files only and no account, session,
  profile, or private-content data.
