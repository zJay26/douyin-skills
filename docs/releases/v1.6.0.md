# douyin-skills v1.6.0

Updates are now optional and discoverable from the CLI. Automatic checking is
enabled by default every **6 hours** and can be turned off. A new release only
produces a notice; users choose whether to download or install it.

## What's new

- `check-update` checks the latest stable GitHub Release on demand.
- `update-status` shows saved settings and cached check results offline.
- `update-config --auto-check off` disables background checks;
  `--auto-check on` enables them. `--interval-hours` optionally changes the
  default 6-hour interval, and `--download-dir` selects where packages go.
- A hidden worker starts with `doctor` or browser commands, persists check
  timestamps and uses a singleton process lock. It never downloads or installs
  automatically. Normal JSON results can carry an optional `update_notice`.
- `download-update --version vX.Y.Z` downloads only the selected stable version
  and verifies the ZIP against the published SHA-256 checksum.
- `install-update --version vX.Y.Z --confirm` updates an unmodified official
  portable installation, stages and validates dependencies first, and retains
  the old installation as a backup. No confirmation means no download/install.
- Official release archives now include a deterministic file/hash manifest.

## Upgrade notes

Install v1.6.0 manually once to receive this feature. Git and Skill-manager
installs support checks and downloads; use Git or the original manager to
upgrade them. Portable in-place installation requires the manifest included
from v1.6.0 onward. Local edits and conflicting files are preserved by refusing
automatic replacement. Accounts and browser profiles are preserved.

Checks run while the local worker and computer are running. After reboot,
the next normal invocation starts it again. No OS service or startup task is
registered. A user can continue using the current version without acting on
the notice. Details and commands are in the [update guide](https://github.com/zJay26/douyin-skills/blob/v1.6.0/docs/UPDATES.md).

## Validation

Regression coverage includes defaults, disabling/re-enabling, persisted
6-hour timing, network-failure throttling, selected-version downloads,
checksum failures, safe archive paths, explicit confirmation, local changes,
dependency failures, installation backups and directory-switch rollback.
The release gate also runs existing Python/Node tests, synthetic page-state
fixtures, a real Chrome smoke on a local synthetic page, Ruff, repository
checks and reproducible release/extraction checks on Windows and Ubuntu CI.
These checks do not claim live Douyin account or publishing validation.

Download `douyin-skills-v1.6.0.zip`, `SHA256SUMS` and the privacy-safe `demo.gif`.
Verify the checksum, extract the complete ZIP, then run `npm ci` and
`python scripts/cli.py doctor`.
