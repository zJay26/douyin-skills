# douyin-skills v1.0.0

`v1.0.0` is the first stable release of `douyin-skills`: five composable Agent Skills and a local JSON CLI for guarded Douyin web workflows.

The release focuses on a narrow, honest contract. An Agent can inspect the environment, work with a local Chrome session, discover public content, prepare a photo post, and perform one-at-a-time interactions. Human verification remains visible, publishing requires a separate confirmation, and an uncertain result is reported as uncertain.

## Highlights

- English-first onboarding with a complete [Chinese guide](../../README.zh-CN.md).
- Five Skills for environment, authentication, discovery, photo publishing, and basic interactions.
- A single machine-readable CLI boundary for Agent integrations.
- Named, local Chrome profiles with loopback-only CDP access.
- Explicit `validate-publish` and `click-publish --confirm` stages.
- Separate result states for confirmed, failed, blocked, and clicked-but-unconfirmed actions.
- A 40-second privacy-safe [Demo GIF](../../assets/demo.gif) generated entirely from synthetic data.
- Windows and Ubuntu CI, Ruff checks, repository integrity checks, and a reproducible release archive.

## Install

With OpenClaw:

```bash
openclaw skills install git:zJay26/douyin-skills@v1.0.0
```

Or download `douyin-skills-v1.0.0.zip` from the GitHub Release, verify it against `SHA256SUMS`, extract the complete folder, and run:

```bash
npm install
python scripts/cli.py doctor
```

## Upgrade from an earlier checkout

Keep local account data outside the repository (the default is `~/.douyin-skills/`), then move the code checkout to the release tag and refresh the locked Node.js dependency:

```bash
git fetch --tags
git checkout v1.0.0
npm ci
python scripts/cli.py doctor
```

If you previously downloaded an unversioned ZIP, extract v1.0.0 into a new folder instead of merging directories. Do not copy or publish the local Chrome profile as part of the upgrade.

## Validation scope

The tagged commit is gated by Python unit tests, a Node.js CDP bridge test, syntax checks, Ruff, repository presentation checks, deterministic packaging, and Demo GIF metadata checks. The automated matrix covers Windows with Python 3.13 / Node.js 24 and Ubuntu with Python 3.9 / Node.js 18.

The Demo GIF is an explanatory artifact, not a recording of a real account. No live account login, captcha, interaction, or publish action runs in CI. See the full [validation and support boundaries](../VALIDATION.md).

## Known limitations

- Douyin can change URLs, selectors, page states, and platform policy independently of this release.
- Captcha, identity checks, and risk controls require the user and are never bypassed.
- Photo posts are supported; video publishing, comments, direct messages, drafts, scheduling, and bulk operations are not.
- A `publish_clicked_unconfirmed` result must be checked manually and must not be retried blindly.
- macOS is not in the automated CI matrix.
- OpenClaw is the documented client path; other Agent Skills clients need their own integration validation.
- The architecture can inform adapters for other social or creator platforms, but v1.0.0 ships only the Douyin implementation.

## Privacy and safety

Account configuration and Chrome profiles stay on the user's machine by default. Do not upload `~/.douyin-skills/`, cookies, QR codes, phone numbers, screenshots containing private content, or browser profiles to an Issue or Discussion. Review [`SECURITY.md`](../../SECURITY.md) before reporting a sensitive problem.
