# douyin-skills v1.5.0

This release improves browser error handling, page selection, local account
storage, and Agent integration. It also closes an unsafe photo-note toggle
fallback and expands release validation.

## New capabilities

- `capabilities` lists all 30 commands with arguments, defaults, limits,
  effect categories, and explicit confirmation requirements, without Chrome.
- `browser-status` diagnoses an existing debugging endpoint without starting
  Chrome or changing tabs. Titles and URLs require `--include-tabs`.
- Global `--target-id` explicitly selects an existing page. A missing session
  creates a dedicated tab for navigation/form preparation; follow-up publishing
  requires an existing form instead of reusing an unrelated tab.
- `update-account` changes an account description while retaining its profile
  and port.

## Reliability fixes

- Extracted the Python CDP client into `browser_runtime.py`, retaining
  `douyin.cdp` compatibility imports. Payloads use UTF-8 stdin to avoid Windows
  argument limits and keep content out of process arguments.
- Enforced loopback HTTP and advertised WebSocket endpoints in the bridge.
  JavaScript exceptions, navigation errors, malformed responses, connection
  loss, and bounded timeouts are reported as errors.
- Preserved unknown outcomes when publish, comment, or toggle dispatch loses
  its result. A known click followed by a failed verification remains
  unconfirmed. Neither case permits automatic retries.
- Removed positional like/favorite clicks on photo-note action bars. Missing
  or conflicting state evidence now blocks both photo and video toggles.
- Added process locks and atomic writes for account changes; invalid Windows
  directory names, duplicate ports, and case-colliding names are rejected.
- Made argument errors JSON and disabled abbreviated flags, including
  abbreviated `--confirm`. `doctor` checks the Node minimum version and keeps
  dependency diagnostics available when account configuration is corrupt.

## Validation and packaging

The release gate includes 141 Python regression tests, 11 Node HTTP/WebSocket tests,
19 synthetic page-state fixtures, Ruff, repository checks, and real Chrome
smoke tests on a synthetic local page. Windows and Ubuntu CI also build the
release twice, compare archive bytes and checksums, and run the packaged
offline CLI after extraction. Release builds reject uncommitted tracked files.

The local Chrome smoke verified navigation, Unicode and native editor input,
local upload, one synthetic click, and JavaScript exception propagation. It did
not use a real Douyin account. Automated checks do not establish live Douyin
page compatibility or confirmed publishing; see [validation boundaries](https://github.com/zJay26/douyin-skills/blob/v1.5.0/docs/VALIDATION.md).

## Upgrade notes

The result-contract version is now `1.1`. Existing commands retain their
defined outcomes; clients must additionally handle `publish_outcome_unknown`,
`comment_outcome_unknown`, and toggle `outcome_unknown: true`. `clicked: null`
means execution is uncertain, even when `success: false`. Do not retry.

Account configuration and profiles are preserved. Old temporary session
pointers are not adopted automatically. Resume an existing form by listing
local tabs and selecting its `--target-id`; details are in
[runtime diagnostics and migration](https://github.com/zJay26/douyin-skills/blob/v1.5.0/docs/RUNTIME.md).

Download `douyin-skills-v1.5.0.zip`, `SHA256SUMS`, and the privacy-safe `demo.gif`.
Verify the named ZIP against `SHA256SUMS` before extraction, then run `npm ci`
and `python scripts/cli.py doctor` from the extracted project.
