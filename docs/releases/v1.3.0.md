# douyin-skills v1.3.0

`v1.3.0` adds a bounded public-comment workflow and hardens the live Douyin
page paths exercised by discovery, interaction, authentication, and photo-post
preparation.

## What's included

- `python scripts/cli.py comment-video` can fill and submit one public comment
  when the page exposes a recognizable composer and send control.
- Controlled editors such as the current DraftJS composer use native CDP text
  insertion instead of direct DOM text mutation.
- Comment results distinguish confirmed, clicked-but-unconfirmed, unavailable,
  text-not-applied, and existing-draft states. An unconfirmed send is never
  retried automatically.
- `get-interaction-state` reads like/favorite state without clicking; already
  active controls are not toggled again.
- Login checks tolerate a bounded transient verification interstitial while
  preserving persistent captcha/risk pages as human checkpoints.
- Hot-topic extraction prioritizes the current semantic list container.
- Photo-post preparation accepts the current Creator Center route, waits for
  upload-ready evidence, rejects truncated or rewritten fields, and restricts
  music fallback selection to semantic enabled “使用” controls.

## Install or upgrade

With OpenClaw:

```bash
openclaw skills install git:zJay26/douyin-skills@v1.3.0
```

For a manual checkout:

```bash
git fetch --tags
git checkout v1.3.0
npm ci
python scripts/cli.py doctor
```

If you use the GitHub Release, download `douyin-skills-v1.3.0.zip` and
`SHA256SUMS`, verify the checksum, and extract the package into a new
directory. Local account data remains outside the repository by default and
must not be copied into a release package.

## Validation scope

The release gate covers 94 Python unit tests, 16 privacy-safe synthetic
fixtures, repository integrity validation, the 960×540 privacy-safe Demo,
Node.js syntax and CDP tests, Ruff lint and format checks, and a reproducible
release build.

The dated live smoke run confirmed environment readiness, a reused logged-in
Chrome session, public search and detail lookup, 20 hot topics, read-only
like/favorite state, a public share URL, and one page-confirmed public comment.
The photo-post flow reached a ready state with an uploaded synthetic image,
exact title/body values, and selected music; no publish click was issued.

These checks validate the result contract and the observed environment. They
do not guarantee current compatibility for every account, video/note page,
selector version, captcha, interaction, or publishing flow. A page-confirmed
comment is not a guarantee of permanent visibility after moderation or
ranking changes.

## Boundaries

- Only the Douyin adapter ships in this release.
- Comment replies, direct messages, video publishing, draft management,
  scheduling, and bulk operations remain unsupported.
- Fixtures are synthetic and privacy-safe; they are not captured HTML or live
  page evidence.
- Captcha, identity checks, and risk controls are surfaced for human handling
  and are never bypassed.
- Publishing still requires validation and a separate explicit confirmation.
- No account, session, profile, QR code, phone number, or private-content data
  is included in the release package.
