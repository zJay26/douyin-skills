# douyin-skills v1.0.1

`v1.0.1` is a reliability release for the page-state decisions behind login, discovery, detail reading, and photo publishing. It adds a versioned library of synthetic, privacy-checked fixtures and makes the production command paths use the same classifiers exercised by those fixtures.

The result contract remains `1.0`. Existing commands and their safety boundaries are unchanged.

## What changed

- Added 11 sanitized JSON fixtures covering signed-out and authenticated login, human verification, search results, unreadable search pages, readable and drifted detail pages, complete and incomplete publish forms, and confirmed/unconfirmed publish outcomes.
- Extracted shared classifiers for login, risk evidence, search readability, detail availability, publish validation, and publish certainty.
- Connected those classifiers to the real login, search, detail, and publish runtime paths rather than maintaining a test-only model.
- Added a standard-library privacy and schema validator that rejects session material, phone numbers, email addresses, local profile paths, embedded images, and non-canonical URLs.
- Added focused regression tests and a Windows/Ubuntu CI fixture-validation step.
- Documented the fixture schema and safe contribution workflow.

## Why it matters

Browser automation often fails gradually: a page still loads, but the signals used to interpret it change. A small, reviewable state library makes those decisions explicit and gives contributors a safe way to reproduce a drift report without publishing a real page dump or account session.

These fixtures test result semantics, not current live-page compatibility. They do not prove that a particular account, selector set, captcha, interaction, or publishing flow works against today's Douyin pages.

## Install or upgrade

With OpenClaw:

```bash
openclaw skills install git:zJay26/douyin-skills@v1.0.1
```

For a manual checkout:

```bash
git fetch --tags
git checkout v1.0.1
npm ci
python scripts/cli.py doctor
```

If you use the GitHub Release, download `douyin-skills-v1.0.1.zip` and `SHA256SUMS`, verify the checksum, and extract the package into a new directory. Local account data remains outside the repository by default and must not be copied into a release package.

## Validation scope

The tagged commit is gated by:

- 48 Python tests, including seven fixture/runtime integration tests;
- one Node.js CDP bridge test;
- fixture schema, expected-state, URL, and privacy validation;
- repository links, English visual assets, version metadata, and Demo GIF checks;
- Ruff lint and formatting;
- Windows (Python 3.13 / Node.js 24) and Ubuntu (Python 3.9 / Node.js 18) CI;
- two reproducible builds of the versioned ZIP and a fresh-extraction smoke test.

See [Validation and support boundaries](../VALIDATION.md) for the distinction between automated evidence and a dated manual run.

## Known limitations

- The fixtures are synthetic abstractions, not stored HTML, screenshots, cookies, or recordings of a real account.
- Douyin can change URLs, selectors, page states, and policy independently of this release.
- Captcha, identity checks, and risk controls remain human-required and are never bypassed.
- Photo posts are supported; video publishing, comments, direct messages, drafts, scheduling, and bulk operations are not.
- An unconfirmed irreversible action must not be retried automatically.
- macOS and Agent Skills clients beyond the primary documented OpenClaw path are not in CI.
- No other social-platform adapter ships in v1.0.1.
